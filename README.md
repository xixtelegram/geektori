# داشبورد فروش استیکر — گیکتوری

ابزار تحلیل فایل فروش فصلی طراح‌ها. کاملاً سمت‌کلاینت (فایل هیچ‌جا آپلود نمی‌شود).

## ساختار ریپو

```
.
├── index.html          ← داشبورد اصلی (GitHub Pages از اینجا سرو می‌شود)
├── data/
│   └── sample.xlsx     ← فایل نمونه فصل فعلی
├── assets/             ← در صورت نیاز CSS/JS/فونت جدا
└── README.md
```

## راه‌اندازی روی GitHub Pages

1. یک ریپوی جدید بساز (مثلاً `giktori-sticker-dashboard`).
2. محتویات این فولدر را داخل ریشه ریپو کپی کن و push بزن.
3. در Settings → Pages:
   - Source: Deploy from a branch
   - Branch: `main` (یا `master`) / root
4. چند دقیقه صبر کن تا آدرس `https://USERNAME.github.io/REPO_NAME/` فعال شود.

### بارگذاری فایل نمونه
دکمه «نمونه فعلی» فایل `data/sample.xlsx` را از همین ریپو fetch می‌کند.  
هر فصل جدید فقط همان فایل را با نام `sample.xlsx` جایگزین کن و commit بزن.

## استفاده برای طراح‌ها

1. فایل اکسل فروش فصل را از گیکتوری بگیر.
2. صفحه داشبورد را باز کن → «آپلود اکسل» یا Drag & Drop.
3. فیلتر کن، نمودارها و جدول را ببین، خروجی CSV یا Excel بگیر.

### ستون‌های مورد انتظار فایل اکسل
- `استیکر` (نام محصول)
- `variant 1 attributes` (جنس / نوع برش / زبان کیبورد و ...)
- `variant 2 attributes` (ابعاد)
- `تعداد فروش فصل`
- `قیمت`
- `مجموع`
- `variant id` (اختیاری)

## نکات مهم

- **حریم خصوصی**: پردازش ۱۰۰٪ در مرورگر است. هیچ دیتایی به سرور ارسال نمی‌شود.
- **آپلود به فولدر `data/` توسط طراح‌ها**: چون GitHub Pages استاتیک است، طراح نمی‌تواند مستقیم فایل را روی ریپو بنویسد.  
  گزینه‌ها:
  1. **پیشنهادی**: طراح فقط فایل را لوکال آپلود می‌کند و تحلیل می‌کند (حریم خصوصی کامل).
  2. اگر می‌خواهی آرشیو مرکزی داشته باشی: طراح فایل را برای ادمین بفرستد → ادمین داخل `data/` کامیت کند (یا با GitHub Actions + توکن).
- فایل‌های با پسوند عجیب مثل `.xlsx.xls` هم پشتیبانی می‌شوند (محتوا مهم است نه پسوند).

## توسعه محلی

فقط `index.html` را با یک سرور استاتیک باز کن (مثلاً `npx serve .` یا Live Server در VS Code) تا `fetch('data/sample.xlsx')` کار کند. باز کردن مستقیم `file://` ممکن است CORS بدهد.

## باگ‌فیکس‌های این نسخه نسبت به نسخه اولیه

- رفع XSS (escape کردن تمام متن‌های کاربر)
- دکمه نمونه واقعی از `data/sample.xlsx` لود می‌شود
- نمودارها با فیلترها همگام هستند
- استخراج بهتر جنس/سایز برای برش و کیبورد
- گرید KPI مناسب موبایل
- فیلترهای ثانویه جمع‌شو
- دکمه ریست فیلترها
- حالت لودینگ
- پیام خطای واضح‌تر
- خروجی Excel علاوه بر CSV
- برچسب نمودارها + tooltip کامل
